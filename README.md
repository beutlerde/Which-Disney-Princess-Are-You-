# ✨ Which Disney Princess Are You? ✨

A magical Disney Princess personality quiz featuring 250 questions, 12 princesses, and a gorgeous animated result screen.

## 🌟 Features

- **250 questions** across 10 categories — draws 35 fresh ones every play
- **12 Princesses** — Cinderella, Ariel, Belle, Jasmine, Mulan, Rapunzel, Moana, Tiana, Aurora, Snow White, Elsa, Raya
- **Visual card options** — flip cards, color swatch pickers, illustrated choice cards
- **Per-category animated backgrounds** — each category has its own aesthetic
- **Magic Mirror loading reveal** — animated mirror fogs up and clears dramatically
- **Royal Profile result** — Royal Title, Traits, Royal Story, Compatibility bars, Personal Crest, Style Picks
- **Per-princess result world** — Elsa gets snowflakes, Ariel gets bubbles, Tiana gets fireflies
- **Infinite replay** — different 35 questions every time

## 🚀 Deploy to GitHub Pages

1. Create a public GitHub repo named `disney-princess-quiz`
2. Upload all files maintaining the folder structure
3. Go to **Settings → Pages → Deploy from branch → main → / (root)**
4. Your quiz will be live at `https://yourusername.github.io/disney-princess-quiz`
